# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report them privately through GitHub's
[private vulnerability reporting](https://github.com/Chistara/iran-legal-calculators/security/advisories/new)
("Report a vulnerability" on the Security tab). We will acknowledge the report, investigate, and coordinate a fix and
disclosure with you.

Incorrect holiday data or a wrong deadline is a correctness bug, not a security issue — please report it as a normal
issue with a link to the official source (see CONTRIBUTING.md).

## Supported versions

Only the latest released version receives fixes.
